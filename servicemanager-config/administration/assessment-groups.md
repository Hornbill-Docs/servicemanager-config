# Assessment Groups

Assessment Groups are used to group together assessment options that are specific to a business function or service. This allows for a more streamlined and relevant assessment process for users, as they will only see the assessment options that are applicable to their specific context.

## Before you begin

* The setting `app.com.hornbill.servicemanager.assessments.advancedMode` must be turned on to user this feature.
